# Le Comptoir des Saisons — site d'exemple Opteamize

Site d'exemple pour un restaurant (bistrot de saison) à Lausanne. **Commerce fictif** : il sert à montrer aux commerçants ce qu'Opteamize
peut faire, et surtout qu'un site se modifie par simple message à une IA (ChatGPT, Claude).

Réalisé par [Opteamize](https://opteamize.ch). Photos : Unsplash.

- **Hébergement** : GitHub Pages. Toute modification sur `main` est en ligne en 1 à 2 minutes.
- **Modifier** : via le connecteur Opteamize, depuis ChatGPT ou Claude. Les modifications vont d'abord
  dans un aperçu ; rien n'est en ligne tant qu'on ne publie pas.
